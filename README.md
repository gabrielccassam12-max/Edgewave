# Edgewave (Fabric 1.21.1)
Espada com cortes em combo. Botão direito (pode segurar): corte diagonal, diagonal oposto, vertical e giro final, cada um soltando uma onda de corte voadora.
Receita: bloco de diamante em cima, lingote de netherita no meio, graveto embaixo. Também está na aba Combate do criativo. Precisa só do Fabric API.
